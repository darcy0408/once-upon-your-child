  🚀 QUICK GIT SYNC PROMPT - Story Weaver Project
═══════════════════════════════════════════════════════════════

COPY & PASTE THIS TO ANY AGENT:

Execute a git repository sync for the Story Weaver project:

1. Run: git status
   - Report what files have changed

2. Run: git add .
   - Stage all changes (respects .gitignore)

3. Run: git commit -m "[AGENT SYNC | YYYY-MM-DD HH:MM:SS] <your brief description>"
   - Use actual timestamp
   - Description: What you accomplished (e.g., "Completed Stripe integration")

4. Run: git pull origin <CURRENT_BRANCH> --no-edit
   - Replace <CURRENT_BRANCH> with your actual branch name
   - Use "main" if on main branch
   - Use "feature/gui-redesign" if on that branch
   - Use your feature branch name if working on a feature

5. Run: git push origin <CURRENT_BRANCH>
   - Push to GitHub using the SAME branch name from step 4

6. Run: git status && git log -1 --oneline
   - Verify clean state and report commit hash

RULES:
- Always sync to YOUR CURRENT BRANCH (not always main)
- Never force push unless explicitly told to
- Don't commit .env files or secrets
- Sync after completing tasks, not mid-work
- If conflicts occur, report them and ask for help

EXAMPLE FOR feature/gui-redesign BRANCH:
git pull origin feature/gui-redesign --no-edit
git push origin feature/gui-redesign

EXAMPLE FOR main BRANCH:
git pull origin main --no-edit
git push origin main
