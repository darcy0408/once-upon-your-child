## 🔑 Backend Environment Variables (Railway Configuration)

These need to be configured in your Railway project dashboard:

### Required Railway Environment Variables:

1. **`GEMINI_API_KEY`**
   - Description: Google Gemini API key for story/image generation
   - Status: ⚠️ REQUIRED - Obtain from https://aistudio.google.com/app/apikey
   - Configuration: Add in Railway dashboard → Project Settings → Variables

2. **`DATABASE_URL`**
   - Description: PostgreSQL database connection string
   - Status: ✅ AUTO-GENERATED by Railway when you add PostgreSQL service
   - Configuration: Automatically set when PostgreSQL plugin is added

3. **`SENTRY_DSN`** (Optional but recommended)
   - Description: Sentry error monitoring DSN
   - Status: ⚠️ OPTIONAL - Get from https://sentry.io
   - Configuration: Add in Railway dashboard if using Sentry

4. **`SECRET_KEY`**
   - Description: Flask secret key for session management
   - Status: ⚠️ REQUIRED - Generate a random string
   - Configuration: Add in Railway dashboard
   - Example: `python -c 'import secrets; print(secrets.token_hex(32))'`

5. **`ALLOWED_ORIGINS`** (Optional)
   - Description: CORS allowed origins (your frontend URL)
   - Status: ⚠️ RECOMMENDED
   - Configuration: Add in Railway dashboard
   - Example: `https://your-netlify-app.netlify.app`

## 🚀 Deployment Process

### 1. Configure GitHub Secrets (One-time)
```bash
# Add each secret via GitHub UI as described above
# Or use GitHub CLI:
gh secret set NETLIFY_AUTH_TOKEN
gh secret set NETLIFY_SITE_ID --body "db36a9a4-9712-46ff-adac-6477362e60de"
gh secret set RAILWAY_TOKEN
gh secret set RAILWAY_PROJECT_ID --body "36b27716-089f-4441-9b9d-af942a6df7aa"
```

### 2. Configure Railway Environment (One-time)
1. Go to Railway dashboard: https://railway.app/project/36b27716-089f-4441-9b9d-af942a6df7aa
2. Click on your backend service
3. Navigate to **Variables** tab
4. Add each required environment variable listed above

### 3. Add PostgreSQL Database (One-time)
1. In Railway project dashboard
2. Click **+ New** → **Database** → **Add PostgreSQL**
3. `DATABASE_URL` will be automatically set

### 4. Trigger Deployment
Once all secrets are configured:
```bash
# Push to main branch triggers production deployment
git push origin main

# Or manually trigger via GitHub Actions
# Go to Actions tab → Select workflow → Run workflow
```

## 🔒 Security Best Practices

### ✅ DO:
- Store secrets ONLY in GitHub Secrets or Railway Variables (never in code)
- Use different secrets for staging and production environments
- Rotate secrets periodically (every 90 days recommended)
- Use Sentry or similar monitoring for production error tracking
- Enable 2FA on GitHub, Netlify, and Railway accounts

### ❌ DON'T:
- Never commit `.env` files with real secrets to git
- Never share secrets in chat, email, or public forums
- Never log secrets in application code
- Never use production secrets in development environment
