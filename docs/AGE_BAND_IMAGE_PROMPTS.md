# Story Weaver — Age Band Image Prompts
## Optimized for Gemini Imagen 3

**Model:** `imagen-3.0-generate-002` via Gemini API
**Format:** Natural language sentences. No Midjourney flags. Style declared first.
**Negative guidance:** Added inline as "do not include" or "avoid" phrases.

**4 Age Bands:**
- 🌱 **Sprout** (3–5): Warm Pixar-style children's book illustration
- ✨ **Explorer** (6–8): Enchanted storybook fantasy illustration
- 🌌 **Adventurer** (9–11): Cosmic digital fantasy art
- 📖 **Creator** (12+): Graphic novel illustration, dark editorial

**Output specs per type:**
- UI buttons: transparent background PNG, wide rectangular format
- Character cards: portrait format, slight bottom vignette
- Backgrounds: full bleed landscape or portrait
- Orbs/icons: circular format, transparent background
