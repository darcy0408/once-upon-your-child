- `399f2a8b` fix(feelings): share ScrollController in Big Feelings core grid — `_CoreGrid` in `lib/widgets/feelings_cloud_picker.dart` was a `StatelessWidget` wrapping a `GridView.builder` in a `Scrollbar`, with neither widget given a `ScrollController`. On Flutter web the Scrollbar fell back to `PrimaryScrollController` while `GridView` does not auto-attach to it on web/desktop, so the first hover event over the picker threw `Scrollbar's ScrollController has no ScrollPosition attached`. Converted `_CoreGrid` to a `StatefulWidget`, instantiated a single `ScrollController` in state, passed it to both `Scrollbar(controller:)` and `GridView.builder(controller:)`, and disposed it. Confirmed `_SecondaryGrid` and `_TertiaryGrid` do not wrap a Scrollbar so no parallel fix is needed.
