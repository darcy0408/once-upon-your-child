## Accomplished
- Fixed photo→cartoon avatar producing long-haired output for short-haired boys (commit `01859be6`). Two coupled changes:
  - `backend/services/avatar_generation_service.py::generate_custom_avatar` — prompt template updated to (a) preserve hair length, style, and color from the reference photo, (b) add an explicit "Gender Presentation" directive that names the gender and forbids defaulting to long flowing hair unless the photo shows it. PNG/WebP uploads (likely from screenshots / phone shares) were being mislabelled. Both now use the magic-byte detector already in `gemini_image_generator._detect_mime_type`, same as `generate_pet_avatar` does.
