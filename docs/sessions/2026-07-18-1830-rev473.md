## Findings raised (full detail in the PR #473 review comment)

1. **`saga_state.nemesis` now carries an instruction, and nothing validates it on return.** All four saga builders emit a conditional into the JSON *value* slot (`"keep 'Gigawatt' if they remain the saga's defining unresolved nemesis after this Issue, otherwise 'Cipher Zero'"`) where the slot previously held a literal name the model copies verbatim. The return path does not check it: `_normalize_saga_state` in `backend/services/story_service.py` (~line 1975) only calls `.strip()`, and `backfill_saga_state` in `backend/services/superhero_validation.py` (~line 135) only tests key truthiness. If the model ever copies instead of resolving, that string becomes the stored nemesis name, renders to the child on the Saga Record screen (`lib/screens/saga_record_screen.dart` ~line 135, formatted as `'$nemesis $status.'`), and is fed back into the next Issue as `prev_nemesis` inside a mandate to name that "nemesis" in prose — so it compounds across the saga.
   - **Severity downgraded after review, on the PR author's evidence.** The review posted this as a merge blocker. The parallel session's own close entry (`2d8b683c`) reports a real before/after generation run against gpt-5-mini via OpenRouter — 4 bands, returning-saga fixture — in which the new prompts resolved the instruction correctly **4 of 4** with **zero rule-text leaks**. That is direct empirical evidence against the failure firing, and it was not available when the review was written. Treat finding 1 as **hardening, not a blocker**: the sample is n=1 per band on one model with one fixture, and the consequence is severe and sticky, so a guard is still worth adding — but it should not hold up the merge.
   - Suggested hardening: move the conditional out of the JSON value slot into a prose sentence above the JSON block, leaving the slot a plain placeholder; and/or reject in `_normalize_saga_state` any `nemesis` longer than ~64 characters or containing `keep '` / ` otherwise `.
2. **The prompt-drift detector is not detecting drift (pre-existing; wider than this PR).** `backend/eval/snapshot.py` slices source files by absolute line number, and the anchors in `backend/eval/prompt_registry.py` are badly misaligned: `T6_SUPERHERO_SPROUT` (lines 284-417) covers generic `sections.append(...)` setup code; `T7_SUPERHERO_EXPLORER` (418-577) covers the ages-6-8 age-guidelines block while the real Explorer builder is at line 742; `T8_SUPERHERO_ADVENTURER` (610-782) covers cape-phrase resolution while the real builder is at line 1088. The three hashes PR #473 refreshed changed *only* because the `_AntiheroBrief` dataclass gained six fields near the top of the file and shifted every window; the PR's actual prompt edits (lines 892, 1286, 1577, 2374) fall outside every tracked window and moved no hash at all. The Creator and Adolescent/antihero builders — the ones this PR rewrote most — have **no registry entry at all**, despite the `T10_ANTIHERO_ADOLESCENT` comment at `prompt_service.py` line 2364. The PR author noted the Sprout hash oddity in their own risks but read it as a benign quirk; it is broader than that. Until the registry is re-anchored by function or marker instead of line number, "snapshot refreshed" is not evidence of anything in any PR.
3. **Explorer's fallback still emits the wording this PR removes.** `backend/services/prompt_service.py` line 918 still reads `prev_status or "is back again"`. The Explorer fix exists because "is back" contradicts the different-villain pin; the new test asserting `"is back" not in prompt` passes only because its fixture uses the `still-at-large` status. An empty or unrecognized `nemesis_status` still emits the contradiction. One-word fix: reuse `"is still out there somewhere"`, or mirror the Adventurer band's neutral `"is still a mystery"` (line 1313). **Not addressed by the PR author; still open.**
4. **Low: the bright classic "THE CALLING" branch inherits noir continuity vocabulary.** It now consumes the shared `continuity_block`, which carries the new nemesis-memory line written in noir register ("a rumor, an unanswered message, a glimpse across a room"). Partly pre-existing; this PR widens the mismatch against that branch's stated aspirational intent.
5. **Test gaps:** nothing covers an empty or unrecognized `nemesis_status` on any band (the finding 3 hole), and nothing covers the finding 1 echo path. Also `test_villain_on_page_rule_on_both_crux_phases` asserts three paths despite its name, and `test_adolescent_saga_state_overwrites_resolved_nemesis` omits the "memory line still fires" assertion its Adventurer counterpart has.
