## Accomplished
- `2b347f3e` fix(frontend): unblank production — **P0**. The web app rendered blank on every client for ~2 days. Root cause: commit `f0edb28c` (2026-05-19 15:04, S-08 security audit) narrowed the nginx CSP `connect-src` from the `'self' https: wss:` wildcard to two pinned origins (Railway backend + Sentry). Flutter Web's CanvasKit loads `canvaskit.js` from `https://www.gstatic.com` (covered by `script-src`) but that script then `fetch()`es `canvaskit.wasm` from the same origin — and `fetch()` is governed by `connect-src`, not `script-src`. With gstatic absent from `connect-src` the wasm fetch was CSP-blocked, the engine never initialised, blank page. The symptom was masked by the same-day Railway platform outage (MT-168 / MT-177) — when Railway recovered, the CSP regression was still live but the blank page got attributed to the outage and MT-177 closed assuming prod was healthy. Fix adds `https://www.gstatic.com` to `connect-src` and rewrites the comment block to document the dual `script-src` + `connect-src` requirement. Deploy verified live by Darcy — app renders again.
