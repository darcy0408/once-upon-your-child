## Accomplished

- **Themes / characters_featured / emotional_arc feature shipped end-to-end** (commit `2706b347`). Anonymous-user persistence is gated correctly (Story.user_id FK is satisfied since anonymous IDs map to real `user` rows via `/auth/anonymous`).

Before today, production had **no DATABASE_URL set** — backend silently fell back to `sqlite:///app.db` inside the container with no volume. All user/character/story state was ephemeral and wiped on every redeploy. Stripe was the only source of truth for subscriptions.

- **Wired `DATABASE_URL=${{Postgres.DATABASE_URL}}`** on both `story-weaver-app` (Flask) AND `lovely-perfection` (Celery worker). Both services write to the DB; sharing requires real Postgres, not SQLite-on-a-volume (Railway volumes are per-service, and `CELERY_TASK_ALWAYS_EAGER=false` in prod means the worker container handles generation independently).
