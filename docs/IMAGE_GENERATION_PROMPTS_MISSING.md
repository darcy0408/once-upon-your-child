## PART 4 — Adolescents Clicked Button States (2 images)
`age_band_assets/adolescents/ui/`

**Art direction:** These are processed variants of the existing normal state buttons. To make them feel like effective buttons that the user is really "picking," they should be **slightly smaller** and **slightly brighter** than the normal state. This creates a satisfying visual feedback of the button being pressed and reacting with light.

---

### `continue_button_clicked.png`
```
UI button asset, clicked/pressed state. This image is a transformed version of the normal 'continue_button.png'. The clicked state must be 95% of the original size (creating a 'press-in' effect) and 15% brighter (creating a 'glow' response). The dark obsidian/charcoal material should appear slightly more luminous, and the teal/cyan crystalline edges should flare up slightly. This version provides the tactile feedback that the button has been activated. Same overall design and text as normal state. Rendered on pure black background.
```

### `make_magic_normal_clicked.png`
```
UI button asset, clicked/pressed state. This image is a transformed version of the normal 'make_magic_normal.png'. The clicked state must be 95% of the original size (creating a 'press-in' effect) and 15% brighter (creating a 'magical activation' response). The magical purple/violet gradients should glow with 15% more intensity, and the golden sparkles should appear more vivid. This version makes the user feel the magic reacting to their touch. Same overall design and text as normal state. Rendered on pure black background.
```

## Post-processing with ImageMagick

To generate the clicked states from the normal states using the **"Smaller & Brighter"** rule, run the following commands (requires ImageMagick):

### 1. Continue Button (Clicked)
```bash
magick continue_button.png -resize 95% -modulate 115,100,100 continue_button_clicked.png
```

### 2. Make Magic Button (Clicked)
```bash
magick make_magic_normal.png -resize 95% -modulate 115,100,100 make_magic_normal_clicked.png
```

### 3. Feelings Icons (Optional Pressed States)
If you wish to create "active" or "pressed" versions of the Feelings icons:
```bash
magick happy.png -resize 95% -modulate 115,100,100 happy_pressed.png
# (Repeat for all 8 emotions)
```

**Note:** If using the project's `process_buttons.py` script, ensure the parameters match these values (0.95 scale and 1.15 brightness multiplier).
