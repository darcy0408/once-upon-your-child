## 📝 Naming Convention

When you download each image, rename it using this pattern:
```
[age]yo_[skintone]_[haircolor]_[hairstyle]_[gender].png
```

**Examples:**
- `5yo_verylight_blonde_short_fem.png`
- `7yo_dark_black_afro_masc.png`
- `9yo_mediumdark_black_braids_fem.png`
- `7yo_light_auburn_medium_androgynous.png`

## ⚡ Quick Workflow

1. **Copy prompt** from this document
2. **Paste into Midjourney** Discord
3. **Wait for generation** (~30 seconds)
4. **Upscale** the best version (U1, U2, U3, or U4)
5. **Download** high-res image
6. **Rename** using convention above
7. **Save** to `C:\dev\story-weaver-app\avatarImages\midjourney_core\`
8. **Repeat** for next prompt!

## 💡 Pro Tips

**Quality:**
- Always use `--v 6` for best Pixar-style quality
- Use `--ar 1:1` for square portraits
- If a face looks weird, regenerate with `/imagine` again

**Speed:**
- Use Fast mode for your first 100 avatars
- Switch to Relax mode if you run out of fast hours
- Generate in batches of 10 for organization

**Variations:**
- If you LOVE one result, click "Vary (Strong)" to get similar ones
- This helps create family resemblances or variations
