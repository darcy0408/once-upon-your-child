# Feelings Quest — Cloud Face Image Prompts (Midjourney)

All images go in: `assets/feelings_faces/clouds/`  
Filename = emotion ID + `.png` (e.g. `happy.png`, `playful.png`)

---

## ⚙️ How To Generate

1. Paste any prompt below into Midjourney Discord
2. After generating, pick the best variant (`U1`–`U4`)
3. Download and remove the background — use **remove.bg**, **Adobe Firefly**, or Midjourney's own `/describe` + "Remove BG" in the editor
4. Save as transparent PNG and drop into `assets/feelings_faces/clouds/`
5. Add each new filename to `assets:` in `pubspec.yaml` under the `assets/feelings_faces/clouds/` folder

**Shared settings used in every prompt:** `--ar 1:1 --v 6 --style raw`

---

## 🎨 Base Style Reference

All clouds should look like the same character — a round, puffy white/pastel cloud with big cartoon eyes and an expressive mouth. Think **Pixar Cloud (from "Partly Cloudy") meets a children's emoji sticker book**.

> "a cute fluffy round cloud character, soft pastel cloud body with rounded bumps on top, large expressive cartoon eyes, [EXPRESSION], isolated on plain white background, transparent-style, no background elements, bold outlines, children's sticker style, soft drop shadow, --ar 1:1 --v 6 --style raw"

## 📁 Asset Setup Checklist

Once all images are generated and background-removed:

1. **Create the folder** (if not yet created):
   ```
   assets/feelings_faces/clouds/
   ```

2. **Add to `pubspec.yaml`** under `flutter > assets`:
   ```yaml
   - assets/feelings_faces/clouds/
   ```

3. **Run** `flutter pub get` after updating pubspec

4. The app will automatically pick up the cloud images — no code changes needed. The `_CloudEmotionCard` widget tries `clouds/{id}.png` first, then falls back to the plain face images.

---

## 🎯 Priority Order

Generate core emotions first (7 images) — they appear on the opening screen and make the biggest impression:

1. `happy.png` → `sad.png` → `angry.png` → `fearful.png`
2. `surprised.png` → `bad.png` → `disgusted.png`
3. Then secondary emotions by most-used core group
