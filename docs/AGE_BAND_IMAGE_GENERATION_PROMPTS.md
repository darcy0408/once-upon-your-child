# Story Weaver — Age Band Image Generation Prompts

This document centralizes the optimized image generation prompts for all seven age bands in the Story Weaver application. These prompts are designed for use with **Gemini Imagen 3/4** (`imagen-3.0-generate-002` or `imagen-4.0-generate-001`).

## Model Configuration & Universal Guidelines
- **Format:** Natural language sentences.
- **Style Priority:** Style is declared first in the `style_base`.
- **Isolation:** For UI elements, use the `-- THE CHARACTER/ELEMENT MUST BE ISOLATED ON A PURE SOLID BLACK BACKGROUND` suffix to ensure clean transparency masking in the app.
- **Safety:** Always child-safe, no violence, no photorealistic human faces (stylized 3D preferred).
